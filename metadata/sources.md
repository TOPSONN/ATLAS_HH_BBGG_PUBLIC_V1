## Access limits and reproducibility

HEPData record pages/JSON and attempted YAML/CSV/ROOT exports returned HTTP 403 through the web client and/or Ubuntu Python HTTP client. This means ACCESS_UNVERIFIED, not missing tables or a proven absence of a workspace. DataCite HTTP 200 supplied the collection/version and 30 table descriptions. Table values, attachment listings, matrices, likelihood formats and journal-version agreement remain unverified. The failed `/limitations` URL was corrected to the linked `/limitations_pp` page, which returned HTTP 200; the audit uses the corrected source.

The research collision APIs 80000/80001 and the direct publisher-PDF request hit a local 4 MiB response guard. This is a deliberate retrieval bound, not evidence that the remote resources are unavailable. Their collision coverage is supported by the umbrella and official coverage documentation; complete child file indices were not retained. The publisher PDF was inspected with the web PDF reader.

Reproduction of the metadata checks needs only a public HTTP client and Python standard library. Example commands (metadata only, no event files):

```bash
curl --fail --location --max-time 30 \
  https://opendata.cern.ch/api/records/93915 --output /tmp/record93915.json
sha256sum /tmp/record93915.json
curl --fail --location --max-time 30 \
  https://api.datacite.org/dois/10.17182/hepdata.160696.v1 --output /tmp/hepdata-v1.json
python3 - <<'PY'
import json
with open("/tmp/hepdata-v1.json") as f:
    a = json.load(f)["data"]["attributes"]
parts = [x["relatedIdentifier"] for x in a["relatedIdentifiers"]
         if x["relationType"] == "HasPart"]
print(a["version"], len(parts))
print("\n".join(parts))
PY
```

For file-count/sample checks, inspect `metadata._files` in the GamGam records and `_file_indices` in research Higgs records; do not open their ROOT URIs. Extract `_mc_<DSID>.` from the 373 GamGam filenames, join to `dataset_number` in versioned `extras/metadata.csv`, and inspect physics_short/process/keywords/description.
