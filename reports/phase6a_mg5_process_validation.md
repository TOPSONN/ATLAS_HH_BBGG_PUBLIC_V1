# Phase 6A process and finite phase space

Actual process: `import model sm-no_b_mass`; `define p = g u c d s b u~ c~ d~ s~ b~`; `generate p p > b b~ a a QCD=2 QED=2`. MG5's actual `help generate` confirms `=` means `<=`. Photons require QED order 2 and the remaining tree continuum vertices QCD order 2, so this contribution is alpha_s^2 alpha_em^2. Generated grouped output: four representative subprocesses / 110 diagrams, in qq and gg groups; charge-conjugate/flavour permutations include b-initiated scattering. Pure electroweak QED=4 content, loop-induced contributions and all NLO corrections are excluded. There is no shower, decay-chain detector simulation or HH signal.

The model is the bundled SM UFO at the pinned MG5 source, using its no_b_mass restriction: MB=0, ymb=0, light quarks massless, diagonal CKM. It has no separately established standalone model release number; the exact source identity and hashes pin it. This is a five-flavour massless hard process with five-flavour CTEQ6L1 PDFs (built-in table, ID 10042), alpha_s(MZ)=0.130 and LO one-loop running. Param-card aS=0.118 is the model default; hadronic running alpha_s follows the selected PDF and the actual event AQCDUP is 0.1238062 at 125 GeV. EW inputs: aEWM1=132.507, GF=1.16639e-5 GeV^-2, MZ=91.188 GeV; MW is derived. AQEDUP=0.007546771.

Both beams are 6500 GeV; fixed muR=muF1=muF2=125 GeV, explicitly a study choice without an optimization claim. The actual banner run cards include pta=25, etaa=2.5, ptb=20, etab=5, draa=drab=drbb=0.4, ptgmin=0, ickkw=0 and systematics_program=none. maxjetflavor=4 controls cut classification so b-specific cuts apply, while the explicitly generated initial proton still includes b and bbar. Generation cuts do not change the five-flavour hard process into a four-flavour scheme.

Positive photon/b pT and all pairwise separations regulate the relevant tree soft/collinear regions; eta bounds give the declared finite domain. The photons are direct matrix-element photons separated from all final b partons. There is no smooth-cone isolation or fragmentation component. At higher orders a proper isolated-photon convention and fragmentation/isolation treatment would be needed; these LO separation cuts are not a full infrared-safe NLO observable or reconstructed ATLAS selection.

All final events have exactly b, bbar and two photons, plus two incoming partons; the independent validator additionally checks the actual cuts, PDFs, event scales/couplings and source/card consistency. A separate pp>aa tree process was physically tested for self-service at 14 TeV, and is clearly not a bbgg substitute.
